## Überblick
Magic spielen ist manchmal aufwendig, denn man benötigt die physischen Karten und diese kosten teilweise viel Geld.
Virtual Tavern bietet eine Möglichkeit schnell ein par Runden mit einem neuem Deck zu spielen.
Es lassen sich bequem Decklisten importieren, alternativ kann man aus fünf vorgegebenen Decks eins auswählen.
Selbsterstellte Decks werden auch gespeichert, wenn man einen Nutzeraccount erstellt hat.

## Wichtige Voreinstellungen
Damit die Karten die richtigen Bilder haben muss zuvor eine API angebunden werden, diese kann aus Legal Gründen leider nicht bereitgestellt werden.
Nutzer können diese in der Deck Ansicht hinterlegen.
Button "API" ich empfehle hier folgende API zu nutzen `https://api.scryfall.com/`,
es können natürlich auch andere kompatible APIs genutzt werden.

## Spielen
Über Play, kann man einen neuen Raum erstellen (Name benötigt min. 3 Zeichen).
Um einem Raum beizutreten muss der Host seinen Raumcode (oben links neben dem Raumnamen) teilen.
Zu Begin wählt jeder Spieler sein Deck und seine Lebenspunkte (20 oder 40) aus.
Das Spielen läuft wie in echt, Spieler sind selbst verantwortlich sich an die Regeln zu halten,
(fast) alle notwendigen Funktionen werden von der Anwendung bereit gestellt.
Die UI ist intuitiv und lässt sich auch mit Hotkeys effizient benutzten.
Eine Liste der Hotkeys kann man im Hauptmenu unter "Settings" finden oder jederzeit in einem Spiel über den Button "Hotkeys".
